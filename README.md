# FAME CAFÉ — Website V1

Erste echte Website-Grundlage für FAME CAFÉ Gummersbach.

## Enthalten
- feste Farbwelt aus dem Konzept
- 50/50 Coffee × Matcha Hero
- begleitender Half/Half Split durch die Story
- Sticky Scroll Story für Barista Coffee und Matcha-Aufbau
- Matcha Ablauf: Ice → Coconut Water → Matcha → Lid + Straw
- Açaí, Café Experience, Menü-Demo, Barista und Visit-Bereich
- responsive Desktop / Tablet / Mobile
- native Scroll-/Reveal-Animationen ohne Framework-Abhängigkeit

## Start
Einfach `index.html` im Browser öffnen.

## Wichtig
Die Bilder sind aktuell lizenzierte Unsplash-Demobilder und werden später durch die echten FAME-Fotos ersetzt. Menüpreise und Standortdaten sind bewusst noch nicht erfunden.
